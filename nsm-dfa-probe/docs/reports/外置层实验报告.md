# 外置层（神经记号文件）实验报告

## 设计动机

把"思维状态"从模型内部/上下文纸带中**外置到磁盘文件**：
模型除了读输入纸带，还读写一个"神经记号文件"（激活通路 + 状态记号）。
用空间（磁盘）换时间（免重算/免长上下文），绕开上下文长度墙。

## 三个实验

### A. 激活通路文件：可审计、可重放的思维轨迹

Executor（k=10）执行 L=1000 字符串，每步把**激活通路记号**写盘：
- 注意力 argmax 的转移索引（"查了哪条表"）+ 解码状态 id（"当前在哪"）。

结果：

| 指标 | 值 |
|---|---|
| 执行准确率 | 100% |
| **纯凭文件重放准确率** | **100%**（不需要再跑模型） |
| 记号文件大小 | 5.5 KB（1000 步） |
| 重放加速 | ~76 万倍（查表 vs 神经网络） |

**含义**：激活通路文件 = 可审计、可验证、可重放的"思维轨迹"。
每步查了哪条规则、到了哪个状态，全部落盘；复核只需查表。

### B. 分段执行 + 外置状态向量：固定窗口处理任意长度

L=20000，每 1000 位一段，**段末把激活向量 r 写盘**，下段从盘恢复继续。

结果：**分段 acc=100%，与一次性全跑完全一致**（10.1s vs 12.7s）。

**关键发现（意外收获）**：最初用"解码的状态 id"作为段间恢复，**失败（acc=False）**。
必须保存**激活向量本身**（r，value 空间），符号状态不可恢复分布式表示。
这恰好证明"神经记号"必须是激活/分布式记号，而非符号——与用户"神经记号"直觉一致。

**含义**：计算窗口固定（1000 位），处理长度无上限。这就是"空间换时间"：
每段只保留 O(1) 的状态向量，历史全部落盘。

### C. 记忆化缓存：重复前缀免重算

100 个查询共享 500 位前缀，缓存前缀状态后：

| 条件 | 耗时 |
|---|---|
| 无缓存（全部重算） | 33.7s |
| 缓存前缀（只算一次+后缀） | 3.8s |
| **加速** | **9.0x** |

**含义**：外置状态文件天然支持记忆化——相同前缀的中间状态直接复用。

## 与整体设计的关系

```
输入纸带(符号) ──► LLM/Executor ──► 输出
      ▲                            ▲
      │        神经记号文件         │
      └── 激活通路(转移索引+状态) ──┘
          + 段间状态向量 r
          + 记忆化缓存
```

- **外置层 = 压缩的历史**：上下文只留"当前状态"，历史落盘为记号。
- **主纸带 + 辅助记号带**：双纸带架构，辅助带承担可验证的复合计算。
- **辅助解码器**（NL 中间层实验已证）：LLM 发指令记号，Executor 执行。
- 与 Phase 1/2 的完整闭环：状态复合不能靠概率模型（M0）→ 显式记忆执行器（Phase 2）
  → 状态/通路外置到文件（本实验）→ 窗口固定、可审计、可记忆化。
