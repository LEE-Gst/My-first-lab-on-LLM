 ## quantum-conv-investigation
 
做了什么
从"量子门是如何工作的"出发,一路追问到"量子卷积到底能不能赢经典",最终产出一份完整的技术文档 + 五个可复现实验 + 一个 GitHub 仓库。整个过程是一条不断收敛的探索链:

探索主线(20 轮对话的思维轨迹):

打地基:量子门 = 幺正矩阵;量子加速是选择性的(Shor 指数级、Grover 平方级);"并行坍塌"不是免费午餐(Holevo 界锁死读出);
修正直觉:经典靠"大量复制结构"(加法器→乘法器→浮点),量子靠"可逆 + 退算 + 相位记账";浮点(离散伪造连续)的量子对应物是振幅估计(连续进、离散出);
形成命题:能否构造 $M$,用有限次 $O(1)$ 操作超越一次完整 $O(x\to y)$?→ 拆出三个先决条件:结构、摊销、只取所需;
落点选型:选卷积层当战场——循环结构在 QFT 下对角化,Cooley–Tukey 就是天然的"四层级分解";
逐环实测:结构精确性 → 真实核的秩 → 截断的任务代价 → 优势因子 → 量子电路验证 → 墙钟时间;
