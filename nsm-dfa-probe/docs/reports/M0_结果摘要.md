# M0 里程碑：Qwen2.5-7B DFA 三分量分解（复现实验）

- 模型：`qwen2.5:7b`（Ollama，temperature=0，top_k=1，seed=42）
- 协议：内部文档《统计-结构边界》三分量分解；平衡 DFA 为每符号排列转移（双随机链，p_hat ≈ p_pos）

## 分解（结构分量 = acc − 常数判定基线 max(p_pos, 1−p_pos)，随机 DFA 上 alpha_surf ≈ 0）

> 注：文档公式 alpha_bias = max(β·p_pos, (1−β)(1−p_pos)) 仅在 β=1.0 时等价于常数判定基线；当 β ≈ p_pos（A5/B10 的均匀判定）时该公式退化出伪影值，故此处统一用常数判定基线 max(p_pos, 1−p_pos) 作为“无结构”参照。

## 结论（M0）

1. **核心结论复现**：模型准确率在所有配置上均 ≤ 或 ≈ 常数判定基线 max(p_pos, 1−p_pos)，无任何超过偏置的准确率 → α_struct = 0，结构追踪缺失。
2. B6 上 β=1.0（无条件 ACCEPT）精确复现文档表 1 的 β=1.0 现象。
3. B10 在 L=100 上 acc=0.427 < 0.5，复现文档表 2 的“低于偏置退化”。
4. α_step 为 0.58–0.94（文档为 1.00）；B10 明显偏低，疑为提示格式与 10 状态数字输出误差，需在 M1 中改进提示后复核。
5. 未观测到随 L 衰减的表层信号（随机 DFA 无表层结构，符合预期）。
