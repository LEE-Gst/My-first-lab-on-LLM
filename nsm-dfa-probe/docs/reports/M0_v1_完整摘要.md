## 3. 结论

1. **直接提示复现文档核心结论**：qwen2.5:7b 在平衡 DFA 上 α_struct = 0；B6 β=1.0 无条件 ACCEPT；B10 出现低于偏置退化。
2. **CoT 并未闭合结构缺口**：qwen2.5:7b 的 CoT 在 B6 上反而劣于直接提示（0.40 vs 0.53），在 B10 上略有提升（0.73 vs 0.47）但远未达到 1.0。说明一般指令模型的 CoT 不足以可靠执行长 DFA 追踪。
3. **单步能力存在但非完美**：改进提示后 B6 step=0.90、B10 step=0.71，仍低于文档报告的 1.00；提示格式与状态数对 α_step 影响显著。
4. **方法学修正已写回源文档**：随机转移表的 p_hat 偏斜问题已在 `statistical_structural_boundary_zh.md` 与 `structural_derivation_zh.md` 中加注。

## 4. 对 NSM 提案的启示

- 现有 7B 指令模型即使配合 CoT 也无法稳定实现 δ*，强化了“把串行深度内化进架构”的动机。
- 下一步（版本 2）应验证：非线性递归 + 逐位置监督的 NSM-100M 是否能让 α_struct > 0 且不随 L 衰减。
