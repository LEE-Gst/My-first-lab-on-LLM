# A1 报告：递归程序执行探针

## 结论

**Executor 架构成功扩展到递归程序**：1.3M 参数的 RecursiveExecutor 对未见过的递归程序
（线性递归 fact/sum、双递归 fib、迭代 countdown、随机栈程序），在训练深度内实现
**100% 全轨迹精确执行**（pc + 8 寄存器 + 栈指针，每步全对）。

**深度泛化不是免费的**：超出训练深度的执行会失败，且失败边界随训练深度外移——
模型学会的是"在训练深度包络内精确执行"，而不是抽象的递归。

## 架构（Neural DFA Executor → ProgramExecutor → RecursiveExecutor 的演化）

```
程序 spec：每条指令 = opcode token + 操作数 token（id 确定性解析 op/reg/imm）
状态 = (pc, R0..R7, sp, stack[48])
  - pc：pc_emb 锚定，取指注意力（键=纯 pc 嵌入，CE 过程监督）
  - 寄存器：val_emb 锚定，显式槽位
  - 栈：混合槽位（val_emb 存值 / pc_emb 存返回地址）
  - sp：**机械化更新**（由 op 语法决定 ±1/0，不学习不嵌入 → 深度无关）
语义：MLP([op_emb, pc, val(reg_a), val(reg_b), imm, 栈顶]) → 写回值 + 下一 pc
更新：STE（前向纯嵌入锚点，梯度走软路）
```

## 训练配方（C1 三重教师强制的扩展）

四重教师强制 + 计划采样退火（前 50% 全程 → 50-80% 退火 → 后 20% 全自主）：
1. 取指槽（防错误指令污染语义学习）
2. 寄存器历史（防一次写错全盘皆错）
3. pc 表示（防 pc 错后监督矛盾）
4. sp（后改为机械化，见下）

## 开发中发现并修复的三个深度泛化障碍

| 障碍 | 症状 | 修复 |
|---|---|---|
| sp 用按整数学习的嵌入 | 没见过的深度无嵌入 → 必崩 | **sp 机械化**（op 决定 ±1，不学） |
| mov/算术没见过大值 | fib(6) 把 mov R4,R0（值6）算成 5 | randarith 随机程序覆盖全值域 |
| push/pop 没见过大值 | fact(9) 把栈顶 9 解码成 8 | randarith 加 push/pop 对 |

每个障碍都通过**逐步诊断第一个分歧点**定位——纸带式轨迹监督让失败点精确可见。

## 最终结果

**训练深度内（in-distribution），n=40/配置：**

| 程序类型 | 深度 | exact | pc | reg | sp |
|---|---|---|---|---|---|
| fact（线性递归） | n≤10 | **1.000** | 1.000 | 1.000 | 1.000 |
| sum（线性递归） | n≤10 | **1.000** | 1.000 | 1.000 | 1.000 |
| **fib（双递归）** | n≤6 | **1.000** | 1.000 | 1.000 | 1.000 |
| countdown（迭代） | n≤10 | **1.000** | 1.000 | 1.000 | 1.000 |
| randarith（随机+栈） | — | 0.975 | 1.000 | 0.985 | 1.000 |

**深度泛化（超出训练深度）：**

| 程序类型 | 测试深度 | exact | 说明 |
|---|---|---|---|
| fact | n=11-14（训≤10） | 0.300 | pc/sp 0.68，值误差经 jz 级联 |
| sum | n=11-14 | 0.000 | 同上 |
| fib | n=7-8（训≤6） | 0.000 | 轨迹 200-450 步，误差累积 |

## 关键科学发现

1. **递归在训练深度内被完全解决**——包括双递归。call/ret/栈的语义全部可学。
2. **深度泛化 ≠ DFA 长度泛化**。DFA 上 L=50→1000 是免费的（状态空间有限且全覆盖）；
   递归深度泛化不免费，因为**寄存器值流经数据依赖分支（jz），值误差会改变控制流并级联**。
   失败边界 = 训练深度，且随训练加深外移（修值覆盖后 fact 从 n=8→9 崩变为 n=10→11 崩）。
3. **逐层诊断方法论有效**：三个失败模式（嵌入深度上限、值覆盖、栈值覆盖）都是通过
   "打印第一个分歧步"定位的——过程监督不仅帮助训练，也让 debug 精确到步。

## 局限（诚实写入草稿）

- 深度泛化未解决：模型不学"抽象递归"，只学"包络内执行"。
  候选解：循环展开数据增强 / 相对深度表示 / 课程式无限加深训练（成本线性增长）。
- 模板递归：只验证了 fact/sum/fib/countdown 四类结构，相互递归、多参数函数未测。
- 值域 mod 16、栈深 48、指令 ≤32 槽——规模边界。
